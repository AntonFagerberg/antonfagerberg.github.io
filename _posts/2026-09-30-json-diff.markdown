JsonDiff (clever name pending) is a MacOS app I created just for myself to compare json snippets (something I do a lot at work). It's a Swift project mainly "vibe coded" with Claude. It has everything I need, it's exactly the way I want it and I enjoy using it a lot. Bespoke software if you'd like.

![JsonDiff main window](/images/projects/jsondiff.png)

### Feature list
- Auto-formatting / pretty printing json on paste
- Supports partial / broken json
- Synchronized scrolling between panes
- Drag 'n' drop file support
- Align blank lines or multi line diffs
- Highlights row and individual characters (see 'ss' vs 'zz')
- Support for VSCode themes
- Font selection setting
- `Cmd+Shift+1/2` clears pane 1/2 and pastes the current clipboard
- `Cmd+1/2` switches to pane 1/2
- Runs on Apple Silicon and Intel
