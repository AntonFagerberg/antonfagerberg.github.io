A book from the extremely popular head coach of Nike Running. Bennet seems like a really nice guy and the writing style feels very personal.

It is mostly not technical, it's empowering and there is a lot of feel good vibes. Everything is sprinkled with personal anecdotes. There is not a lot of content in it and a technical summary would be very short. If you want to start running then I think it will be valuable, if you're already a runner and know the basics then you can probably skip it.
