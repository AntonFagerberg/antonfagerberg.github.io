This is a a really good epic sci-fi. I would describe it as Hollywood-ish in that it could easily be turned into a block buster film / tv-series in the likes of Hunger Games. 

My main gripe about this book is that it starts with 25% world building / setting up the story and that part is really good but then it's 75% "battle" which can become a bit tedious if you're not into that. Nonetheless, it was really good and it has me wanting more. It seems to be a trilogy (or perhaps even more) so I need to dig into that in the future.
